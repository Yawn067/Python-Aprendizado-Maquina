# Projeto de Classificação com Machine Learning

Este repositório contém os exercícios e estudos desenvolvidos durante o curso da Alura de Análise de Dados com Machine Learning. O objetivo é explorar diferentes algoritmos de classificação e técnicas de pré-processamento de dados para construir modelos preditivos.

## Estrutura do Projeto

O projeto está organizado em aulas, cada uma focando em um aspecto diferente do aprendizado de máquina:

*   `aula1.py`: Introdução à classificação com `LinearSVC` e avaliação de acurácia.
*   `aula2.py`: Aplicação de `LinearSVC` em dados de tracking e divisão de dados com `train_test_split`.
*   `aula3.py`: Predição de finalização de projetos, diferenciando modelos lineares (`LinearSVC`) e não-lineares (`SVC`), explorando a necessidade de escalonamento de dados e visualização das fronteiras de decisão.
*   `aula4.py`: Comparação de modelos (`SVC`, `DummyClassifier`, `DecisionTreeClassifier`) para predição de venda de carros, com engenharia de features e visualização de árvores de decisão.

## Como Usar

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/Yawn067/Python-Aprendizado-Maquina
    cd Python-Aprendizado-Maquina
    ```
2.  **Instale as dependências:**
    Certifique-se de ter Python instalado. As principais bibliotecas utilizadas são `pandas`, `scikit-learn`, `seaborn`, `matplotlib` e `graphviz`.
    ```bash
    pip install pandas scikit-learn seaborn matplotlib graphviz
    ```
3.  **Execute os scripts:**
    Você pode executar cada arquivo `aulaX.py` independentemente para ver os resultados:
    ```bash
    python aula1.py
    python aula2.py
    # etc.
    ```
